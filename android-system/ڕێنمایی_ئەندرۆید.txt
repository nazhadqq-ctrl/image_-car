  🚗 سیستەمی تۆمارکردنی زانیاری ئۆتۆمبێل — ئەندرۆید (Android System)
======================================================================

ئەم فۆڵدەرە هەموو پێداویستییەکانی ئەندرۆیدی تێدایە بۆ ئەوەی لەسەر تابلێت یان
مۆبایلی ئەندرۆید بەبێ نێتۆرکی ناوخۆیی و ڕاستەوخۆ بە پەبلیک ئایپی کار بکات.

----------------------------------------------------------------------
🔹 ڕێگای یەکەم: خێراترین ڕێگا بەبێ دابەزاندنی فایل (PWA Native App)
----------------------------------------------------------------------
١. لەسەر تابلێت یان مۆبایلە ئەندرۆیدەکە وێبگەڕی Google Chrome بکەرەوە.
٢. ئەم ناونیشانە بنووسە:
   👉 http://62.201.232.190:3002

٣. سێ خاڵەکەی سەرەوەی وێبگەڕەکە دابگرە (سەرەوە لای ڕاست یان چەپ).
٤. کلیک لەسەر (Install app) یان (Add to Home screen / ئیزافە بۆ شاشەی سەرەکی) بکە.
٥. ئایکۆنی پرۆگرامەکە دەکەوێتە سەر شاشەی تابلێتەکەت ڕێک وەک ئەپڵیکەیشنی ڕاستەقینە!
٦. بە 4G / 5G یان هەر وایفایەک بێت لە هەر شوێنێک پەیوەندی بە سێرڤەرەکەتەوە هەیە.

----------------------------------------------------------------------
🔹 ڕێگای دووەم: دروستکردنی فایلی فەرمی APK لە ڕێگەی Android Studio
----------------------------------------------------------------------
١. بەرنامەی Android Studio بکەرەوە.
٢. کلیک لەسەر (Open Project) بکە و ئەم فۆڵدەرە هەڵبژێرە:
   📁 android-system/android

٣. لە مینیۆی سەرەوە بڕۆ بۆ:
   Build -> Build Bundle(s) / APK(s) -> Build APK(s)

٤. فایلی (app-debug.apk) ئامادە دەبێت و دەتوانیت بە فلاش یان تێلێگرام بیخەیتە سەر هەموو تابلێتەکانی ئەندرۆید.

----------------------------------------------------------------------

----------------------------------------------------------------------

(🌐 Server URL / پەبلیک ئایپی سێرڤەر)
دەتوانیت هەر کات ویستت ئایپی سێرڤەرەکە لە فایلی config.js بگۆڕیت (بۆ نموونە: http://62.201.232.190:3002).
